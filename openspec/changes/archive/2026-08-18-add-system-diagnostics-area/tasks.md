## 3. Persistence (`smalog-storage`)

- [x] 3.1 Add `migrations/optional/sqlite_diagnostics.sql` and

      (occurred_at)`, `(level, seq DESC)`, `(target, seq DESC)`.
- [x] 3.3 Add `enable_sqlite_diagnostics`/`enable_postgres_diagnostics` and
      the matching `disable_*` functions to `schema.rs`, following the
      daily-statistics pattern, and confirm `SCHEMA_VERSION` is unchanged.
- [x] 3.4 Add storage-owned row types and `Db::write_transmissions(&[…])` and
      `Db::write_log_records(&[…])`, each inserting a whole batch in one
      transaction; the app maps the connection-owned `PollTransmission` into
      these types at the boundary, so `smalog-storage` keeps depending only on
      `smalog-observation`.
- [x] 3.5 Add `Db::read_transmissions(filter, since, before, limit)` and
      `Db::read_log_records(filter, since, before, limit)` using keyset paging

      filters pushed into SQL.
- [x] 3.6 Add `Db::prune_transmissions(retention, max_rows)` and
      `Db::prune_log_records(retention, max_rows)`: delete rows older than the
      window measured against the newest stored timestamp, then delete below
      the row-cap watermark, both chunked so one call cannot hold a long write
      lock, returning whether more remains to prune.
- [x] 3.7 Add `Db::diagnostics_stats()` returning retained count and oldest

- [x] 3.8 Extend `tests/storage.rs` and `tests/postgres.rs`: enable/disable

      keyset paging to both ends, each filter, age pruning at the window

      backlog, and a backwards clock step.
